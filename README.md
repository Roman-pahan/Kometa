# Quasarex — сайт-обменник

Платформа обмена: THB ↔ RUB, THB ↔ USDT, юани через Alipay, плюс любые направления, которые вы добавите сами
(планируются аргентинский песо, игровые ключи и скины).

Домен: **quasarex.ch**. Развёртывание — см. [deploy/DEPLOY.md](deploy/DEPLOY.md).

## Возможности

- **Главная**: курсы по всем направлениям, калькулятор обмена, создание заявки.
- **Личный кабинет**: свои заявки со статусами, комментарии оператора, верификация.
- **Верификация**: фото паспорта и лица **только с камеры** (загрузка готовых файлов исключена),
  обязательные ФИО и телефон, к которому привязан банк. Фото шифруются на диске.
- **Зашифрованный чат** с оператором: сквозное шифрование, сервер хранит только шифротекст.
- **Админка** (`/admin.html`): заявки, клиенты, верификации, чат, курсы и направления, настройки.
- **Telegram-уведомления**: новые заявки, верификации и сообщения чата приходят администратору в бот.
- **Восстановление пароля** по ссылке на почту.

## Запуск

```
npm install
npm start
```

Сайт: http://localhost:3210

## Администратор

При первом запуске создаётся администратор `admin@obmen.local`. Пароль берётся из
`ADMIN_PASSWORD`; если переменная не задана, сервер придумывает случайный и печатает его
один раз в лог запуска. **Смените пароль сразу** — Админка → Настройки → «Смена пароля».
Задать свой при первом запуске: `ADMIN_EMAIL=... ADMIN_PASSWORD=... npm start`.

## Курсы

Базовые курсы тянутся с open.er-api.com каждые 15 минут (USDT считается равным USD).
Итоговый курс клиента = кросс-курс минус ваша наценка в %. Для любого направления можно
задать ручной курс — он имеет приоритет над автоматикой. Всё настраивается в админке,
логика источника изолирована в `rates.js` — заменить провайдера курсов можно правкой одного файла.

## Статусы заявок

`Новая → В работе → Ожидает оплаты → Выполнена` (или `Отменена`).

## Шифрование и ключи

Три независимых секрета, каждый нужно сохранить в надёжном месте:

| Что | Где хранится | Что защищает | Потеря означает |
|---|---|---|---|
| `UPLOADS_KEY` (или `data/secret.key`) | переменная окружения / постоянный диск | фото паспортов и секреты в базе | фото не восстановить, почта и бот отключаются |
| Ключ чата администратора | localStorage браузера | переписка с клиентами | старая переписка нечитаема |
| Пароль администратора | вы | доступ в админку | сброс через базу |

Ключ чата экспортируется кнопкой «Экспорт ключа» в админке, вкладка «Чат».

Ключ шифрования ищется в таком порядке: переменная `UPLOADS_KEY` → `data/secret.key` →
`secret.key` в корне (так лежали ключи у прежних установок, такой ключ переносится в `data/`
автоматически). **На сервере задавайте `UPLOADS_KEY`**: только переменная окружения гарантированно
переживает деплой. Если ключ сменится, сервер напишет об этом в лог при запуске — прежние фото
и зашифрованные настройки (пароль почты, токен бота, секрет Google, токены доступа) читаться перестанут.

## Переменные окружения

| Переменная | Зачем | Если не задана |
|---|---|---|
| `UPLOADS_KEY` | ключ шифрования фото и секретов в базе | ключ берётся из `data/secret.key`; секреты в базе остаются открытым текстом |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | учётка администратора при первом запуске | `admin@obmen.local` со случайным паролем из лога |
| `PUBLIC_URL` | адрес сайта в ссылках писем и уведомлений | адрес берётся из заголовка запроса |
| `DB_FILE` | путь к базе (нужен тестам) | `data/exchange.db` |
| `STATS_TZ_SHIFT` | часовой пояс статистики | `+7 hours` |

## База данных

SQLite-файл `data/exchange.db`, загруженные файлы — `data/uploads` (в зашифрованном виде, `.enc`).
Резервная копия: скопировать папку `data` целиком **и отдельно сохранить ключ шифрования** —
без ключа фото из бэкапа не открыть.
