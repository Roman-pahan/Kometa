# Запуск сайта на Render — по шагам

Домен: **kometa.exchange** (куплен в Porkbun).
Стоимость: $7/мес за сервис + $0.25/мес за диск.

Делайте по одному шагу, не забегая вперёд. После каждого шага можно остановиться.

---

## Шаг 1. Код на GitHub

Render разворачивает сайт из репозитория, поэтому код должен лежать на GitHub.

1. Заведите аккаунт на **github.com**, если его нет.
2. Нажмите **New repository**, назовите `kometa-exchange`, выберите **Private**, создайте.
3. GitHub покажет страницу с командами. Оттуда нужна только строка вида
   `https://github.com/ВАШ_ЛОГИН/kometa-exchange.git` — пришлите её мне, я залью код.

Что попадёт в репозиторий: только исходный код. База, загруженные фото и ключ шифрования
исключены файлом `.gitignore` и на GitHub не уйдут.

---

## Шаг 2. Ключ шифрования

Выполните в PowerShell и **сохраните результат** — это ключ, которым шифруются фото паспортов:

```
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Потеряете ключ — фото верификаций станут нечитаемыми навсегда. Положите его в менеджер паролей.

---

## Шаг 3. Создание сервиса на Render

1. Регистрация на **render.com** (можно через тот же GitHub).
2. **New → Blueprint**, выберите свой репозиторий. Render прочитает `render.yaml` и всё настроит сам.
3. Он попросит заполнить три переменные:
   - `UPLOADS_KEY` — ключ из шага 2;
   - `ADMIN_EMAIL` — ваша почта для входа в админку;
   - `ADMIN_PASSWORD` — придумайте надёжный пароль администратора.
4. Нажмите **Apply**. Первая сборка занимает 3–5 минут.

Проверьте, что в настройках сервиса есть диск (Disk) с путём
`/opt/render/project/src/data`. Без него база будет стираться при каждом обновлении.

---

## Шаг 4. Домен

1. В Render откройте сервис → **Settings → Custom Domains → Add Custom Domain**,
   введите `kometa.exchange`, затем добавьте ещё раз `www.kometa.exchange`.
2. Render покажет DNS-записи. Обычно это:
   - для `kometa.exchange` — запись типа **A** на их IP-адрес;
   - для `www` — запись типа **CNAME** на адрес вида `имя-сервиса.onrender.com`.
3. Зайдите на **porkbun.com → Domain Management → kometa.exchange → DNS**
   и добавьте эти записи ровно так, как показал Render.
4. Подождите 10–30 минут. Render сам выпустит SSL-сертификат, HTTPS включится автоматически.

---

## Шаг 5. Настройка сайта после запуска

База на сервере создастся с нуля, поэтому в админке (`https://kometa.exchange/admin.html`)
нужно один раз заполнить:

1. **Настройки → Название сайта**: `Kometa`.
2. **Настройки → Telegram для связи**: аккаунт, куда пойдут клиенты с сайта.
3. **Настройки → Telegram-уведомления**: токен бота `@ExchangeNewLife_bot` и кнопка
   «Определить chat ID», затем «Тестовое уведомление» для проверки.
4. **Настройки → Почта (SMTP)**: чтобы работало восстановление пароля.
5. **Курсы и направления**: проверить наценки, при необходимости поправить.
6. **Чат → Экспорт ключа**: сохранить строку в менеджер паролей.

Направления обмена создадутся автоматически, все семь.

---

## Резервные копии

Раз в месяц заходите в **Render → сервис → Shell** и скачивайте файл `data/exchange.db`,
либо настроим автоматический бэкап позже. Отдельно храните `UPLOADS_KEY` —
без него фото из копии не открыть.
